# Contributing

Do not add assets, screenshots, fonts, binaries, or generated output unless their license and provenance are documented. Never copy from a proprietary/private watch face or import its Git history. Run `python3 tools/config_inventory.py --check`, `python3 -m unittest tools/test_config_inventory.py`, and the Gradle checks before proposing a change. Local hooks are opt-in and repository-scoped: `git config core.hooksPath .githooks`.
